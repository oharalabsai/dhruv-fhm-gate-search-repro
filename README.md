# dhruv-fhm-gate-search — reproduction package

Generated by the Ohara autoresearch harness from campaign `dhruv-fhm-gate-search` (source of record: the private `oharalabsai/autoresearch` repo).

## Contents

- `workspace/` — the final incumbent and baseline code under test
- `experiments/` — every scored candidate with its pre-registered hypothesis and verdict JSON
- `contract.json` / `CONTRACT.md` — the frozen public problem contract
- `PRIORS.md` / `JOURNAL.md` — the full belief state and decision trail
- `paper/` — the LaTeX paper and compiled PDF
- verifier: NOT included (campaign still live — the battery stays blinded until close).

## Reproduce

1. Read CONTRACT.md for the metric definition and promotion rule.
2. Score any `experiments/*/candidate.py` (or `workspace/incumbent.py`) with the verifier (`scorekeeper/scorer.py` exposes `score`/`score_paired`; batteries regenerate fresh per call — expect fresh-seed variation within the noise floor recorded in each verdict).
3. Verdict JSONs carry provenance stamps (host, harness commit) for every number in the paper.

Papers are human-authored (byline law) with an AI-contribution statement; the harness protocol (pre-registration, blinded scoring, adversarial audit) is described in the paper's methods.
